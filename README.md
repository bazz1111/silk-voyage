# qinglu-handscroll

Cursor skill：把旅行照片做成 3:4 竖版「青绿山水手卷截景」海报。上半保留原图，下半在象牙色空绢里画同场景的横向青绿手卷截段。

源提示词来自 [蛋黄堡 @Hamburgerai](https://x.com/Hamburgerai/status/2095472220520988681)（2026-09-03）。

## 安装

把本仓库放到 Cursor skills 目录，保证 `SKILL.md` 在目录根下：

```text
~/.cursor/skills/qinglu-handscroll/SKILL.md
```

Windows：`%USERPROFILE%\.cursor\skills\qinglu-handscroll\SKILL.md`

新开一轮 Agent 对话后即可使用。

## 用法

丢一张旅行/风景照片，说「做成青绿手卷海报」或点名 `qinglu-handscroll`。必须有照片；一图一海报。

## 文件

- `SKILL.md` — skill 说明与必须逐字使用的 Prompt
